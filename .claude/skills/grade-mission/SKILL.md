# בדיקת "משימת בית חדש"

הבדיקה רצה על מנוי Claude Code של המורה, בלי מפתח API. התוצאה היא **טיוטה**: המורה מייבא אותה ללוח, עורך ושומר. התלמידים לא רואים כלום לפני כן.

## שלבים

1. **מציאת קובץ הייצוא.** הנתיב מגיע בארגומנטים (`$ARGUMENTS`). אם אין נתיב, חפש את `mission-export-*.json` החדש ביותר ב-`~/Downloads` ובתיקיית הפרויקט, ושאל את המורה אם זה הקובץ הנכון.

2. **הכנת חבילות בדיקה.** הרץ מתיקיית הפרויקט:
   ```bash
   node scripts/grade-mission.mjs prepare "<export.json>" [--only ID,ID]
   ```
   הפלט הוא JSON עם `dir`, `toGrade` ו-`alreadyGraded`. צוות שכבר יש לו תוצאה מדולג, ולכן אפשר להמשיך ריצה שנקטעה.
   - אם `toGrade` ריק, דלג ישר לשלב 4.
   - אם יש יותר מ-12 צוותים, ספר למורה שבדיקה של כיתה שלמה עלולה לנצל חלק גדול ממכסת המנוי, והצע `--only` לחלוקה לקבוצות.

3. **בדיקה: subagent נפרד לכל צוות.** כך העבודה של צוות אחד לא משפיעה על הבדיקה של צוות אחר.
   - הפעל עם הכלי Agent, `subagent_type: "general-purpose"`, `model: "opus"`, עד 4 במקביל בכל הודעה.
   - בכל subagent: התוכן המלא של [grader-prompt.md](grader-prompt.md), קרא אותו פעם אחת לפני השלב הזה. אחריו ההוראות הבאות, עם הנתיבים המלאים:

   > קרא את חבילת הבדיקה `<dir>/packets/<ID>.md`. בדוק את העבודה לפי ההוראות שלמעלה.
   > כתוב את התוצאה כ-JSON תקין בלבד, בלי טקסט נוסף, לקובץ `<dir>/results/<ID>.json`, במבנה הבא:
   > ```json
   > {
   >   "teamId": "<ID>",
   >   "criteria": [
   >     {"id": "terms", "level": "excellent|good|needs_improvement", "score": 0, "justification": "..."},
   >     {"id": "accuracy", ...}, {"id": "calc", ...}, {"id": "research", ...},
   >     {"id": "recommendation", ...}, {"id": "organization", ...}
   >   ],
   >   "bonus": 0,
   >   "bonusReason": "...",
   >   "stageFeedback": {"s1": "...", "s2": "...", "s3": "...", "s4": "...", "s5": "..."},
   >   "generalFeedback": "...",
   >   "teacherFlags": ["..."]
   > }
   > ```
   > כל ששת הקריטריונים חובה, והציון של כל אחד בטווח שבמחוון. אל תחשב סך הכול, הוא מחושב בקוד.
   > אל תקרא קבצים אחרים, אל תריץ פקודות ואל תשנה שום דבר מלבד קובץ התוצאה.
   > בסיום החזר שורה אחת: `<ID>: <סכום הציונים>`.

4. **איחוד ובדיקת תקינות.**
   ```bash
   node scripts/grade-mission.mjs merge "<dir>"
   ```
   אם בדוח יש `error` (JSON לא תקין) או `problems` מהותיים, כמו קריטריון חסר או משוב חסר, הפעל מחדש subagent רק לצוות הזה ואחר כך הרץ שוב את `merge`. תיקון קטן של ציון שחרג מהטווח הוא תקין.

5. **דיווח למורה בעברית, בקצרה.**
   - כמה עבודות נבדקו, טווח הציונים והממוצע.
   - צוותים עם `teacherFlags` חשובים, בשורה לכל צוות.
   - הנתיב המלא של `<dir>/mission-ai-grades.json`.
   - איך מייבאים: לוח המורה ← משימת בית חדש ← "ייבוא טיוטות AI" ← בחירת הקובץ.
